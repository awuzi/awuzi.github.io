# Portfolio

Site statique hébergé par GitHub Pages. La page publiée est [index.html](index.html), avec ses styles dans [styles.css](styles.css). Aucun build ni dépendance n’est nécessaire.

Pour déployer, configurer GitHub Pages sur la branche `main`, dossier `/ (root)`. Les modifications de contenu et de style se font directement dans `index.html` et `styles.css`.
